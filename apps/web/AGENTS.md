# AGENTS.md

## Commands

- **Lint**: `bun lint`
- **Format**: `bun format`
- **Type-check**: `bun check`
- **Type Generate**: `bun cf-typegen`
- **Dev**: `bun dev`
- **Build**: `bun build`

## Architecture

- **Stack**: SvelteKit + Tailwind CSS
- **Hosting**: Cloudflare Workers
- **Database**: Cloudflare D1 with Drizzle ORM
